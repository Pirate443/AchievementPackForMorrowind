--------------------------------------------------------------
			Description:
This is a small mod - integration, adds 16 achievements for Morrowind based on 'The Achievement Framework'.
- 13 achievements from the OMW Achievements mod.
- 3 new achievements by Pirate.
- This mod uses the i18n library, includes English and Russian languages.

Can be connected before or after completing quests. If connected after completion, achievements will unlock upon loading a save.
It is recommended that you have The Achievement Framework set to "Mod Authors Choice" for the option about hiding secret achievements.

List of new achievements at the end of the file.
--------------------------------------------------------------
			Requirements:
Morrowind
Tribunal
Bloodmoon
Morrowind Code Patch
MGE XE 0.17.0 + (Run MWSE-update.exe)
The Achievement Framework

Recommended for use with the Morrowind Achievement Collection.

			Installation:
Copy the "Data Files" to your game folder or use a mod manager.
